## 数据快照与来源

为保留本次实验的数据快照，仓库保存 [SlideAudit](https://github.com/zhuohaouw/SlideAudit) 上游提交 `642d490b7c1d2e78a50a631bfd359433397f3ecf` 的 `metadata.csv`、2,400 份标注和 2,400 份描述，以及本次抽样下载的 60 张图片。下载清单、选图依据和数据来源说明保留在第四阶段目录内；原始资料的权利归其原作者。

上游数据以普通文件保存，内部 `.git` 元数据不进入本仓库。重新克隆本仓库后可以直接查看快照和已有分析结果。下载器与完整数据检查都依赖上游 Git 元数据；如需重新下载或完整复查，请在 `实践/ppt_audit_stage1/ml_stage4/` 下先执行 `python download_slideaudit.py --data-dir <新的空目录>`，再执行 `python inspect_slideaudit.py --data-dir <同一目录>`，避免误报上游数据总量。
