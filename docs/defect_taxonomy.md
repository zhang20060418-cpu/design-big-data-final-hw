# 缺陷类型与结果解释

| 类型 | 关注的问题 | 典型证据 |
| --- | --- | --- |
| 字号不合理 `improper_font_sizing` | 文字在页面中的实际可读性、字号及文字角色是否匹配。 | 实际排版范围、字号、文字角色与渲染尺寸。 |
| 内容遮挡 `occluded_content` | 有效文字或信息区域是否被其他对象覆盖。 | 对象顺序、相交区域、透明度和信息区域。 |
| 布局拥挤 `cluttered_layout` | 信息元素、间距和局部密度是否产生阅读压力。 | 对象关系、间距、密度与空间分布。 |
| 溢出或裁切 `content_overflow_cutoff` | 文字、对象是否越出可用范围。 | 页面和对象边界、实际文字排版测量。 |
| 过分留白 `excessive_whitespace` | 信息占用与可用空间是否明显失衡。 | 内容区域、未知区域、空间占用和布局角色。 |
| 异常设计风险 `generative_design_anomaly` | 重复布局、装饰使用等是否值得进一步检查。 | 同文档跨页关系、原生对象与装饰分布。 |

图片语义伪影子项目前不支持；相似布局、装饰较多或出现图片本身不等于确认存在缺陷。

## 状态含义

- `candidate`：发现需要进一步判断的候选及证据。
- `no_candidate_in_available_scope`：在本次可判断范围内未发现候选。
- `unknown`：证据或测量不足。
- `unsupported`：当前能力不支持该范围。
- `not_checked`：本次未执行该项检查。

六类规则分数是启发式风险或优先级，不应当作校准概率。CLIP 辅助概率、结构候选和模型复核结论分别保留来源。用户应结合页面展示、问题对象和证据解释结果，特别留意纯图片、旋转、组合、继承属性和未测量区域。
