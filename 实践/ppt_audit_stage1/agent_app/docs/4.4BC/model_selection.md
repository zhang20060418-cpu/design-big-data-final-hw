# 当前默认检测版本与旧 CLIP 使用决定

核查日期：2026-10-31。本次只核对并明确应用选择，不训练、不调阈值、不重做独立测试、不改研究模型或历史评价工件。

## 默认方案

维持实际已接入的 **six-detector-evidence-routing-r2**，用于“候选筛查 → 按需 LLM 复核”。当前没有找到更新且已有报告支持替换它的六类版本。这里的选择针对当前筛查目的，不声称它在每个标签或每种来源上都是经过独立验证的最优分类器。

| 类别/步骤 | 实际实现 |
|---|---|
| D1 字号、D4 裁切 | 既有专用检测与实际排版边界 |
| D2 遮挡、D3 拥挤 | R2 `evidence_refinement_v2.py` |
| D5 留白 | 已有空间特征方案；冻结阈值 0.3308457711442786 |
| D6 异常设计 | 召回候选与装饰证据修缮；冻结阈值 0.75 |
| 筛查路由 | R2 `routing_v2.py` |
| 模型入口 | `backend/app/services/six_inference_worker.py` |

依据是 `ml_stage4/experiments/recall_precision_refinement_20261030/optimization_report.md`：

| 已使用的开发回归数据 | 参考缺陷页送审覆盖 | FPR | FDR |
|---|---:|---:|---:|
| T100 | 50/50 | 32.00% | 24.24% |
| 六类标签齐全的 400 页合并 | 164/164 | 38.14% | 35.43% |
| G150 单批 | 34/34 | 33.62% | 53.42% |

T100 从原策略送审 89 页降至 66 页，参考缺陷页覆盖没有下降。FPR=FP/(FP+TN)，FDR=FP/(TP+FP)。G150 的 FDR 仍超过 50%，不能用合并值掩盖这个限制。

以上是重复使用的构造开发参考中的**送审覆盖**，不是六类自动分类召回、LLM 最终确认率或独立泛化成绩。T100 自动逐标签仍有 23 个漏项；A05 语义检测仍 unsupported。应用的 ReviewPlanner 另受页面/调用预算约束，因此不能把研究全队列的 164/164 直接说成任意预算下应用的零漏检表现。

## 旧 CLIP 的决定

**本次不将旧 CLIP 加入默认告警并集，也不以其阴性否决 R2 或未知范围兜底。** 保留原四标签插件接口，目前没有部署为默认分类器，不伪装成已启用的模型。

已有证据：

- `stage4k_constructed_diagnostics_20261029/reports/constructed_diagnostics.md` 中，RM 正确类别覆盖参考正页 24/30、告警 41/130；C OR RM 仍覆盖 24/30，但告警升至 88/130。逐标签 D1/D2 各增加一个参考正标签命中，说明 CLIP 并非完全无信号；这仍不足以支持默认增加全部视觉告警。
- `ml_stage4/reports/pptx_g2_independent_evaluation.md` 已有自然 328 页结果中，C 的 F1 工作点触发 213 页复核，正常页误报 199/312，缺陷页检出 11/16。高召回工作点增加复核量，缺陷页检出仍为 11/16。这里仅参考既有结果，没有重新评分或据此调整冻结阈值。
- R2 研究未新增 CLIP 前向或做 C+R2 联合评价，尚无组合净收益证据。图片式页面已经保留额外视觉复核范围，旧 CLIP 的阴性不能证明这些页面正常。

因此，当前采用“较有依据的 R2 专用筛查 + 未决范围补查 + LLM 专用复核”，比直接叠加历史 CLIP 更符合降低无效复核负担的目标。若以后验证旧 CLIP 的补漏或队列排序价值，再通过显式可选接口接入，保持冻结版本、阈值和来源证据；本次不启动这个新实验。
